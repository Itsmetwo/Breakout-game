Breakout Q-Lab

A paddle, a ball and a wall of bricks. Nobody tells the agent how to play. It only learns from what happens when it moves, and it writes what it learns into a small neural network that scores every move: one Q-value for left, stay and right.

How to play

Move the paddle with ← → (or A D), or drag a finger or the mouse across the game board. You get 5 lives: when the ball falls you lose one and a new ball is served; when all 5 are gone, the try is over. The AI plays with 5 lives too. Break as many bricks as you can (Round 1 has 28, Round 2 has 150), then see whether the AI can beat you in Rounds 3 and 4.

The Q-values

A table would need a row for every possible ball position, so the AI uses a small neural network instead. Each row is a situation (a state) and each column is a move (an action). The number is the network’s current guess of how good that move is. Underlined = best known move. The highlighted row is the live game; the others are fixed test situations with the ball coming down, so you can watch it learn to chase the ball.

How the AI learns (Deep Q-Learning)

Each step the AI sees 6 numbers (paddle position, ball position and speed). A network with layers 6 → 32 → 32 → 3 outputs a Q-value per move. While practicing it picks a random move with probability ε (which shrinks over time) and otherwise the move with the highest Q. Every experience goes into a replay buffer; the network learns from 32 random memories at a time, aiming for r + γ · max Q_target(s′, a′), and a frozen copy (the target network) is refreshed every 500 steps.
